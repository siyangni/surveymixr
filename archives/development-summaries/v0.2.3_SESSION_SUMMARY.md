### Technical Insights

**Key Learning**: S4 slots are strict about types. A "data.frame" slot cannot store nested lists even if you try to coerce it. Must declare as "list" type.

**Design Decision**: Single-variable case uses flat structure (test_results$omnibus_test), multi-variable uses nested (test_results$var1$omnibus_test) for backward compatibility with existing tests.

**Naming Convention**: Must match test expectations exactly. Changed from `pairwise` to `pairwise_tests`, `omnibus_F` to nested `omnibus_test$statistic`.

# Plot Class Sizes

Bar plot showing the proportion of individuals in each class.

## Usage

``` r
plot_class_sizes(object, weighted = TRUE, ...)
```

## Arguments

- object:

  A `SurveyMixr` object

- weighted:

  Logical, use weighted proportions? (default: TRUE)

- ...:

  Additional arguments

## Value

A ggplot2 object
